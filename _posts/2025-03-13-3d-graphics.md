This project was a continuation of the C++ 2D graphics project from earlier in the same module. It used similar systems but was adapted to a 3D space. This was a group project, in which I worked with two other students to create a simple system of a spaceship taking off and flying into the distance. This was a very complex implementation and required a lot of hard work from our group but in the end we had a project I was happy with.
