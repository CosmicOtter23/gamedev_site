This was a project in a web development module in the first year of my computer science course at The University of Leeds. The assignment was to create a small website using HTML, CSS and JavaScript. The site could have whatever topic we wanted so I chose reviews of video games as I already had an interest and some knowledge about the subject, meaning I wouldn’t have to write long sections of filler text, I could just write my opinions. I designed a few pages for the site and also added a HTML form for readers to add their own reviews and ratings, which would appear at the bottom of the page for the corresponding game.
