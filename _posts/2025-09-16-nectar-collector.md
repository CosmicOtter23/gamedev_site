This game was made as my submission for Mini Jam 193: Hunters on <a href="https://cosmicotters.itch.io/">Itch.io</a>. Each of these game jams has a theme and a limitation. The theme was “hunters”, and the limitation was “double or nothing”, meaning a submission had to include these two concepts in some capacity. My first idea was for the game to take place a 2D plane, with enemies (hunters) chasing a player, each moving one space at a time. My implementation of the double or nothing limitation was a collectible that spins a wheel, which choose a random element of the game (number of collectibles on screen, enemy speed, etc) and 50/50 doubles it or removes it. This can be helpful for the player by stopping enemy movement briefly or doubling the number of collectibles or hinder the player by increasing enemy speed or removing all collectibles.

I made this game using Unreal Engine. The Itch page and a playable version for my submission can be found <a href="https://cosmicotters.itch.io/nectar-collector">here</a>.
