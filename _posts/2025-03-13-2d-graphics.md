In the 3rd year of my computer science degree at The University of Leeds, I completed a computer graphics module that involved using C++ and OpenGL to render graphics. The first assignment of this module was to generate graphics for a simple game in which the player can control a spaceship flying around. I had minimal experience with C++ at the beginning of this project so it required a lot of time learning the language and using existing programming skills from other languages.
